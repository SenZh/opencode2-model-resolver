## 三、关键发现（本轮最有价值）

**#10 的实测后果**：审查者质疑「无法核实 attachment」促使我实际取证，发现：

1. `Model.Info` **没有** `attachment` 字段（`additionalProperties:false`）→ 原计划写入会失败
2. `Model.Info` **没有**顶层 `reasoning` 布尔字段 → 用户要求的「reasoning 显式写」在 V2 无落点
3. 实测运行时 API 确认：**当前所有模型 capabilities 都是默认值** `{tools:true,input:["text","image"],output:["text"]}` —— 这就是「能力显示全不对」的直接证据

若不做这次实测，实现会写两个无效字段，问题依旧。
